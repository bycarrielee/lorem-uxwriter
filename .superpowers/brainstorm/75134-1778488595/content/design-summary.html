What it is
A web-based AI writing assistant for UX practitioners working on Singapore government digital products. The agent reviews copy against a managed library of approved copy strings, then falls back to writing guidelines and AI generation when no library match exists. Core value: consistency through library-first lookup, with transparent source labelling on every suggestion.
Users
Practitioners — UX writers, content designers, product designers
Secondary — product owners, developers
Access — .gov.sg self-serve signup, or admin invite (for contractors/vendors)
Default — can access all products
Restricted — admin can limit to specific products
Core workflow
1. Practitioner sets context (product, element type, journey stage)
2. Pastes or types copy into editor
3. Clicks Review
4. Agent: queries library → loads foundations → calls Claude
5. Results appear: suggested copy + rationale + source + confidence
6. Practitioner shortlists, edits, or requests more options
Tech stack
Frontend — Next.js
Backend — Next.js API routes
Database — Supabase (PostgreSQL)
Auth — Supabase Auth
AI — Claude API
Content API — Supabase REST (auto-generated)
Agent logic
Step 1 — DB query: product library → global library
Step 2 — Load: element patterns + foundations
Step 3 — Call Claude with all context
Source labels:
· Library match
· Adapted from library
· AI-generated
· AI-generated · lower confidence
Editor UI
Layout — two-panel (input left, results right)
Features:
· Show / hide rationale
· Shortlist options
· Request more options
· Edit AI output inline
· Session history
· Share session (read-only link)
Admin panel
· Copy library CRUD (add, edit, deprecate, import JSON)
· Foundations & patterns editor
· Products management
· Users: invite, promote to admin, restrict product access
· Usage stats: sessions, library hit rate, top element types
Out of scope (v1)
· Multi-product comparison in one session
· Auto-applying copy without human review
· Marketing or long-form content
· Figma / design tool integration
· Real-time collaboration
· SEO / meta copy
· Non-Singapore government standards
