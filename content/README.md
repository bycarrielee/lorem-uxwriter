# Content intake

Drop your source files here before Plan 2. Any format works — Word docs, PDFs, Markdown, screenshots, whatever you have.

---

## foundations/

Writing guidelines that apply across all products.

Drop here:
- Voice and tone guidelines
- Accessibility standards
- Style guide (grammar, punctuation, formatting)
- Localisation/translation guidelines
- Terminology — official agency names, scheme names, approved/avoided terms

---

## patterns/

Element-type-specific copy rules. One file per element type if possible, but dump everything together if that's easier.

Drop here:
- Button copy rules
- Error message guidelines
- Form label guidelines
- Alert/notification guidelines
- Modal copy guidelines
- Navigation labels
- Any anti-patterns / what NOT to do

---

## copy-examples/

Real copy from live products. The more the better — these become the library entries.

Drop here:
- Screenshots of UI with copy
- Spreadsheets of approved copy strings
- Figma exports
- Any existing copy libraries or style guides from specific products (MyLegacy, SGW, etc.)

---

Anything that doesn't fit neatly — just drop it in the root `content/` folder and add a note.
