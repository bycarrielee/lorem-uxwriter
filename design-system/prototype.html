The original message "File upload failed. Please try again." is brief but lacks a recovery path for persistent failures. The revision adds an escape valve without over-explaining. The phrasing "Upload failed" is shorter — consistent with the guideline to front-load the problem type.

  • Error pattern: state what failed, then what to do next
  • Voice: plain language, no jargon, active voice
  • Accessibility: recovery path included for persistent errors
  • Style: sentence case, no full stop on short error messages
