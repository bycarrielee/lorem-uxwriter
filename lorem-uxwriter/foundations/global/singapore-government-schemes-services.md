## Usage Notes

### Abbreviations
When abbreviations are commonly used (shown in parentheses), both the full name and abbreviation are acceptable. Examples:
- Child Development Account (CDA) → "CDA" is acceptable
- Community Health Assist Scheme (CHAS) → "CHAS" is acceptable
- CPF LIFE → Use as shown (not "CPFL")

### Special Cases
- **Child Development Account**: When shortened, use "CDA" not "CDA account"
- **NS55 credits**: Use sentence case (not a proper noun)
- **GST Voucher**: Always specify which component (Cash, MediSave, U-Save, or S&CC Rebate)

### Consistency
- Always use exact capitalization as shown
- Use initial caps for all scheme and service names (they are proper nouns)
- When in doubt, refer to this list rather than improvising

## Quick Search Tips

### Finding Schemes
- Use Ctrl+F / Cmd+F to search for keywords
- Search by category if you know the general domain (Healthcare, Housing, Employment, etc.)
- Common search terms: "bonus", "grant", "voucher", "support", "assistance", "relief"

### Finding Services
- Search by target audience: "senior", "youth", "caregiver", "child"
- Search by service type: "counselling", "care", "programme", "centre"
